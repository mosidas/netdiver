# netdiver

SF 世界を舞台にした 3D アクション。徒歩の TPS ステージと、ポータル間を移動するネット空間の 3D シューティングを交互に繰り返す。

## 概要

- ジャンル: TPS(三人称シューティング)。
- 世界観: SF。巨大で無機質な構造物が続く世界。
- 構造: ステージは 1 本道。ステージのボスを倒すとポータルゲートが出現し、ワープして次のステージへ進む。ポータル間の移動はネット空間として表現し、その区間は 3D シューティングになる。

## 技術スタック

- ゲームエンジン: Godot 4。
- スクリプト: 型注釈付き GDScript を基本とし、性能上のホットスポットは GDExtension へ逃がす。
